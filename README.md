# Wireless Split Mechanical Keyboard

A custom wireless split mechanical keyboard designed from scratch as part of the Hack Club Stasis program.

## Features
- Wireless via Bluetooth (nRF52840)
- Split design with 21 keys per half
- Kailh Choc V1 hotswap sockets
- Column stagger layout
- Battery powered with voltage sensing
- ZMK firmware compatible

## Hardware
- MCU: Seeed XIAO nRF52840
- Switches: Kailh Choc V1 (hotswap)
- Diodes: 1N5819 SOD-123
- PCB designed in KiCad 9.0

## Libraries Used
- marbastlib (switch footprints)
- Panelization.pretty (mousebites)

## Firmware
This keyboard uses ZMK firmware. See the ZMK documentation for setup instructions.

## Status
PCB design complete — pending manufacturing and assembly.
